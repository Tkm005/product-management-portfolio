# Product & Project Management Portfolio

A working portfolio for documenting product and project work, with an emphasis on the problem, decisions, delivery approach, and measurable outcomes.

## Areas of practice

- Product discovery and problem definition
- User stories, requirements, and acceptance criteria
- Roadmap and backlog prioritization
- Project plans, milestones, and dependencies
- Risk and stakeholder management
- Agile delivery, release coordination, and retrospectives
- Product metrics and outcome measurement

## Project case studies

Add a folder under [`projects/`](projects/README.md) for each project. Use the [case-study template](templates/project-case-study.md) and include only information that is safe to share publicly. Replace the template prompts with your real experience; no sample projects or outcomes are fabricated here.

## Suggested case-study outline

1. Context and problem
2. Goals and success measures
3. Role, collaborators, and constraints
4. Discovery and key decisions
5. Plan and execution
6. Results and lessons learned
